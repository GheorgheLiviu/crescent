    Before you run it

      What the installer does

      1. Asks for admin access once, so apps don't each prompt you.
      2. Checks for winget and opens the Microsoft Store if it's missing.
      3. Lets you choose where apps go, or keeps Windows' usual folders.
      4. Installs each app silently with its latest version, skipping ones already installed. Apps whose maker needs a few clicks open last.
      5. Runs your scripts and turns on weekly updates if you asked, then shows a summary.

      App logos belong to their owners. Icons from dashboard-icons, selfh.st icons (CC BY 4.0), Simple Icons and the makers' sites.
